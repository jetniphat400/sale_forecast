## Part 2 -- Which test answers the question

The question: does Top-down forecast more accurately than Direct on the current production scope (the pricelist scope, the current seven-origin backtest), per division? **Neither file tests exactly that.** b3 is PEM101 pilot items only, one split, a window that no longer moves, and has no per-division result. The phaseC file has the right scope (all five divisions, the current seven origins, the current window; the 110 codes outside it have no forecast to test) but pairs only item-averaged errors, which is the robustness variant, and writes no p-value. So the test was **run now** from the current backtest rows (`phaseC_step2_transferability_item_rolling_origin.csv`, 7,004 rows): pairs of (item, origin) mean absolute errors per division, Top-down against Direct and against Naive; then the robustness checks the brief asks for, item-averaged paired t and a Wilcoxon signed-rank test (scipy 1.18, two-sided, default handling of zero differences) on the item-level pairs. Pairs of the same item across overlapping origins are not independent, so the item-origin t is the optimistic one.

Items per division and origins: CI101 13 items, PEM101 144, PEM102 16, PEM103 49, PEM107 112; 7 origins each. Top-down has no forecast (no share) for 8 PEM101 and 2 PEM107 item-origin cells, so those item-origin n are 1,000 and 782 against 1,008 and 784 for Direct and Naive; every item still has at least one origin.
