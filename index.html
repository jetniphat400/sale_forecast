คำอธิบายศัพท์ (Term Definitions)
ADI (Average Demand Interval) = โดยเฉลี่ยกี่เดือนถึงจะขายได้ 1 ครั้ง คำนวณจาก 31 เดือน ÷ จำนวนเดือนที่มียอดขาย เช่น ADI = 3 หมายถึงขายได้เฉลี่ยทุกๆ 3 เดือน ยิ่งสูง = ยิ่งขายนานๆ ครั้ง
CV² = ความผันผวนของ "ขนาด" ออเดอร์ในเดือนที่ขายได้ ค่าต่ำ = แต่ละครั้งขายจำนวนใกล้เคียงกัน / ค่าสูง = บางเดือนขายน้อย บางเดือนขายก้อนใหญ่
Smooth = ขายเกือบทุกเดือน จำนวนใกล้เคียงกัน → พยากรณ์ง่ายที่สุด
Erratic = ขายเกือบทุกเดือน แต่จำนวนแกว่งมาก
Intermittent = นานๆ ขายที แต่พอขายจำนวนใกล้เคียงกัน
Lumpy = นานๆ ขายที และจำนวนไม่แน่นอน → พยากรณ์ยากที่สุด
MPS = PO ที่รับจากลูกค้าแล้ว อยู่ระหว่างรอส่งมอบ (ยังไม่เป็นยอดขายจริง)
